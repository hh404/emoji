# Emoji Search for Alfred

Type `emj`, then a space, followed by a search term; press Return to copy the selected Emoji.

Examples:

- `emj 问号` or `emj ?` → `❓`, `❔`, `⁉️`
- `emj smile` → matching smile Emoji
- `emj 火箭` → rocket Emoji

The workflow runs locally. Pressing Return copies only; it never pastes into the active app.

To install, double-click `Emoji-Search.alfredworkflow` and approve Alfred's import prompt.
